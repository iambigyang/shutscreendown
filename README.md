# 熄内屏（ShutScreenDown）

让 MacBook 和 MacBook Pro  在开着盖子并连接外接显示器的情况下：

- 接上外接屏，内置屏自动熄灭；
- 拔掉外接屏，内置屏自动恢复；
- 效果等同合盖模式，但摄像头、Touch ID、键盘、散热都照常可用。

## 工作原理（大白话）

此 App 调用系统内部的一个接口，告诉系统「这块内置屏不要渲染了」从而将屏幕连背光一起真正关掉，而不是调暗。

安全性设计：

- 这个「关闭」只在**本次登录会话**内有效：注销或重启，内置屏就会恢复，不会永久黑屏。
- App 不存在时（崩溃、被强杀），关闭状态可能残留。为此提供独立的「RecoveryScreen / 恢复内置屏」急救工具，任何情况下双击它即可救回屏幕。

## 安装

### 方式一：直接使用构建产物

项目目录下有现成的两个 App：

| 文件 | 作用 |
|---|---|
| `ShutScreenDown.app` | 主程序（菜单栏运行） |
| `RecoveryScreen.app` | 急救工具，平时用不到（文件名是英文， 中文名是「恢复内置屏」） |

把两个 App 拖入 `/Applications` 即可（**强烈建议**两个都拖，急救工具放这里才能在全黑时用 Spotlight 搜到）。首次打开若提示「无法验证开发者」， 在设置中允许即可。

或者运行安装脚本：

```bash
./scripts/install.sh
```

也可以直接使用 DMG：双击 `ShutScreenDown.dmg`，把两个 App 拖入其中的 `Applications` 快捷方式即可完成安装。

### 方式二：从源码构建

只需要 macOS 自带的 Command Line Tools（在终端运行 `xcode-select --install` 安装），不需要完整 Xcode：

```bash
./build_app.sh
```

脚本会生成两个 `.app` 到项目目录。

## 支持范围与使用前检查（重要）

- **实测环境**：macOS 26.6.2（Apple Silicon，M 系列芯片）。仅此环境经过完整真机测试。
- **未测试环境**：macOS 12 ~ 25 各版本**均未经过测试**。本 App 依赖的系统接口在这些版本中大概率存在，但不作任何保证。
- **未提供构建**：Intel Mac（x86_64）没有构建产物，需自行在 Intel 机器上从源码构建。
- **使用前请先运行接口探测**（无论哪个版本）：

```bash
swift scripts/probe.swift
```

  输出中 `CGSConfigureDisplayEnabled: FOUND` 表示核心接口可用，可以正常使用；
  若为 `missing`，说明当前系统已不支持该接口，**请勿使用本 App**。

## 使用

打开 `ShutScreenDown.app` 后，菜单栏出现一个显示器图标（内置屏关闭时图标带斜杠）。点开菜单：

| 菜单项 | 说明 |
|---|---|
| 内置屏：已关闭 / 开启中 | 当前状态（不可点） |
| 外接显示器：N 台已连接 | 当前外接屏数量（不可点） |
| 盖子：打开 / 关闭 | 盖子状态（不可点） |
| 显示器：内置显示器（开/关） | 内置屏状态（不可点） |
| 显示器：外接显示器 型号名（开/关） | 展开子菜单：关闭/开启此显示器 |
| 关闭内置屏（只用外接） | 手动关闭内置屏；没有其它可见屏幕时不可用（防止全黑无法操作） |
| 恢复内置屏 | 手动恢复 |
| 自动：接外显关、拔掉恢复 | 自动模式开关。勾选后：接外显自动关、拔掉自动恢复 |
| 开机自启（崩溃自动重启） | 勾选后：开机自动运行；App 崩溃后系统会自动把它拉起来 |
| 关于 / 屏幕全黑怎么救 | 自救说明 |
| 退出（自动恢复全部显示器） | 退出 App，所有被关闭的显示器恢复点亮 |

## 行为约定

- **App 的开关状态是唯一权威**：合盖、开盖都不会改变你的设置。设为「关」时，开盖瞬间若内屏被系统点亮，App 会在 1.5 秒内重新关掉（多数情况下系统尊重关闭状态， 屏幕不会闪烁）。
- **不碰电源设置**：本 App 不会修改任何系统电源管理设置（睡眠、唤醒、网络等均无改动）。
- **没有外接屏时拒绝关闭内置屏**：否则你会面对一块全黑的屏幕无法操作。
- **任意一台显示器都可单独关闭/开启**：最后一块可见屏幕永远无法被关闭。
- **外接显示器关闭后的插拔行为**：物理拔出后恢复为亮；同一端口快速插回（显示器 ID 未变）则保持关闭。
- **退出 App 时自动恢复所有被关闭的显示器**。
- **拔线自动恢复时会发系统通知**：首次启动需允许通知权限，可随时在系统设置中调整。

## 屏幕全黑了怎么办

任选其一：

1. **拔掉外接显示器**——App 会自动恢复内置屏。
2. **Spotlight 盲打**（全黑也能操作）：按 `⌘ 空格`，输入「恢复内置屏」或「RecoveryScreen」，回车。
3. **合盖再开盖**，或注销、重启——设置只在本次登录会话有效，重启必然恢复。

## 开机自启与崩溃自愈

勾选「开机自启」后，App 由系统的 launchd 管理：

- 开机登录后自动运行，菜单栏图标照常出现。
- **崩溃自动重启**：即使 App 被强杀，约 10 秒内系统会自动把它拉起来。
- 在 launchd 管理下点「退出」是**真退出**：App 会先从系统注销自己再退出，不会被拉回来。

## 疑难排查

- **日志**：App 的每一步动作都记录在 `~/Library/Logs/ShutScreenDown.log`，出问题时先看它。
- **状态文件**：`~/Library/Application Support/ShutScreenDown/state.json`，保存开关意图与自动模式。
- **扩展坞用户**：拔掉扩展坞（而非单根显示器线）时，系统会短暂残留「幽灵显示器」，本 App 已内置物理连接检测，能正确识别并恢复内置屏。拔线到恢复之间约需 1~2 秒。
- **退出时外屏闪一下**：正常现象。恢复内置屏需要重新调整显示配置，闪一下是系统行为。

## 项目结构

```
Sources/ShutScreenDown/           主程序（菜单栏 App）
Sources/ShutScreenRestore/        急救工具（恢复内置屏）
build_app.sh                      构建脚本（一条命令出两个 .app）
scripts/install.sh                安装脚本（复制到 /Applications）
scripts/make_dmg.sh               打包 DMG（需先运行 build_app.sh）
scripts/probe.swift               验证系统接口是否可用
scripts/test_toggle.swift         开关内屏 3 秒自动恢复（验证用）
scripts/diagnose_windowserver.sh  诊断 WindowServer 卡顿（一般用不到）
make_icon.swift                   图标生成器（构建时自动调用）
monitor.svg                       主程序图标源文件（构建时转绘进图标）
```

## 风险说明

- 本 App 使用苹果未公开的系统接口。该接口**仅在 macOS 26.6.2（Apple Silicon）上实测可用**，其它版本见「支持范围与使用前检查」；苹果可能在未来的系统更新中改动或移除它，升级大版本后建议重新运行 `scripts/probe.swift` 确认。
